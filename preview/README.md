# Konvensi preview desain RuangAjar

Preferensi pengguna untuk pekerjaan desain berikutnya:

- Sebelum perubahan desain baru, tampilkan opsi visual di chat dan selalu berikan rekomendasi beserta alasan singkat.
- Terapkan opsi setelah dipilih pengguna; bedakan konsep gambar, preview interaktif web, dan APK native.
- **Selalu sertakan tombol Light mode / Dark mode pada setiap preview interaktif.** Pastikan form, teks, pesan kesalahan, dialog, dan background dapat dibaca dalam kedua mode. Pergantian mode tidak boleh mengganti state simulasi/role.
- Preview memakai data contoh, bukan kredensial nyata. Jangan memanggil backend atau mengubah data dari simulasi desain.
- Jangan mengklaim perubahan preview sudah masuk APK jika kode native belum diubah dan dibuild.

Preview Android saat ini berada di `preview/android/`.
